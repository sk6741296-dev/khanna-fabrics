# Khanna Fabrics — Luxury Women's Fashion & Lucknowi Chikankari Boutique

A bespoke, editorial demo website created for **Khanna Fabrics**, a premier Indian fashion and women's clothing store established in the historic Inner Circle of **Connaught Place, New Delhi**.

---

## 🏛️ About Khanna Fabrics

Situated in D Block, Connaught Place, Khanna Fabrics is celebrated for authentic handcrafted Lucknowi Chikankari, premium unstitched fabric sets, elegant ready-to-wear kurtis, festive designer suits, and in-house alteration & custom fitting support.

- **Category**: Women's Clothing Store
- **Address**: Inner Circle, D-6&16/1, Radial Rd 5, Connaught Place, New Delhi, Delhi 110001, India
- **Phone**: `+91 11 2341 1929`
- **Hours**: Monday – Sunday: 11:00 AM – 9:00 PM
- **Location Context**: D Block, Connaught Place (Near Rajiv Chowk Metro Station Gate 5/6)

---

## ✨ Features & Architecture

1. **Editorial Hero (`#home`)**: High-impact showroom panorama capturing the heritage colonial architecture of Connaught Place and pastel Chikankari displays.
2. **Signature Collections (`#collections`)**: Editorial lookbook showcasing Lucknowi Chikankari, handcrafted kurtis, artisanal Anarkalis, unstitched suit sets, and handloom dupattas.
3. **The Art of Chikankari (`#chikankari`)**: Storytelling section honoring delicate shadow work, Tepchi, Bakhiya, and Phanda embroidery across fine cottons, georgettes, and silks.
4. **The Boutique Experience & Alteration Atelier (`#experience`)**: Showcasing attentive personal styling hospitality, private fitting rooms, and on-the-spot alteration support.
5. **Curated Customer Testimonials (`#testimonials`)**: Authentic client stories emphasizing fit, craftsmanship, and boutique service (100% star-free, editorial presentation).
6. **Visual Boutique Gallery (`#gallery`)**: Asymmetric responsive gallery featuring authentic local photography of the CP storefront, colonial arches, and fabrics.
7. **Visit Us & Contact (`#visit`)**: Verified address, store hours, direct telephone CTA, walking directions from Rajiv Chowk Metro, and verified Google Maps destination link.
8. **Floating WhatsApp Widget**: Accessible fixed button connecting directly to `+91 11 2341 1929`.
9. **Luxury Minimal Footer**: Clean brand narrative, verified contact details, and site navigation.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Typography**: Playfair Display (Editorial Serif) & Plus Jakarta Sans (Modern Sans-Serif) via `next/font`
- **Icons**: Lucide React
- **Images**: Next/Image with curated authentic local photography

## 🚀 Getting Started

### Development
```bash
npm install
npm run dev -- -p 3008
```
Open [http://localhost:3008](http://localhost:3008) in your browser.

### Production Build
```bash
npm run build
npm start -- -p 3008
```
